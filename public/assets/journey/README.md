# Journey photographs

Drop three files in here and they appear automatically in the "Journey / これまでの歩み"
section. Until then each slot shows a quiet placeholder — nothing breaks.

| file             | chapter                     |
| ---------------- | --------------------------- |
| `graduate.jpg`   | 東京大学大学院 (2017–2019)  |
| `university.jpg` | 東京大学 工学部 (2013–2017) |
| `highschool.jpg` | 東海高等学校 (2010–2013)    |

**Format: 3:2 landscape, ~1800 × 1200 px, JPEG.** Other ratios still work (the frame
crops from the centre), but 3:2 is what the layout is drawn for. Keep each file under
about 500 KB.

To change a filename or add a caption, edit the `photo` / `photoCaption` fields on the
matching entry in `data/profile.ja.ts` and `data/profile.en.ts`.
